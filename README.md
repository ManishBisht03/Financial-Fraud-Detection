# Financial Fraud Detection & Transaction Risk Analytics

## Project Overview
This project analyzes financial transactions to identify fraudulent transaction patterns and understand transaction risks using Python, SQL, and Power BI.

## Tools & Technologies
- Python (Pandas)
- SQL
- SQLite
- Microsoft Power BI
- Excel / CSV

## Dataset Overview
- Dataset: PaySim
- Total transactions: 6,362,620
- Total features: 11
- Fraudulent transactions: 8,213
- Legitimate transactions: 6,354,407
- Fraud rate: Approximately 0.13%

## Key Findings
- Fraudulent transactions represent approximately 0.13% of all transactions.
- Fraud was observed in CASH_OUT and TRANSFER transactions.
- The analysis identified transaction patterns and fraud-related behaviour.
- The total amount associated with fraudulent transactions was approximately 12.06 billion.

## Project Workflow
1. Dataset inspection and cleaning using Python.
2. Data summarization and exploratory analysis.
3. Database creation and analysis using SQL.
4. Interactive dashboard development using Power BI.
5. Presentation of findings through visual reports.

## Power BI Dashboard
The dashboard contains six analytical pages:
1. Fraud Overview
2. Transaction Type Analysis
3. Fraud Trend Analysis
4. Fraud Flagging Analysis
5. Transaction Amount Analysis
6. Transaction Behaviour Analysis

## Repository Structure
- `scripts/` – Python scripts
- `sql/` – SQL analysis queries
- `data/summaries/` – Analysis summary files
- `docs/` – Project report and architecture diagram
- `powerbi/` – Power BI dashboard and screenshots

## Project Scope
This project focuses on historical transaction analysis and visualization. It does not represent a deployed real-time fraud detection system or a newly trained machine learning model.
